## 板块营地重构 - 区分概念/行业板块

### 用户反馈问题
1. 无法判断板块生命周期状态（刚启动/高潮/一日游/主线/退潮）
2. 桑基图流向过于武断，缺乏数据支撑
3. 缺少龙头股和连板梯队明细
4. 轮动应该是日线级别日历，而非流向图
5. **概念板块和行业板块采集策略不同**

### 关键区分：概念板块 vs 行业板块

| 维度 | 概念板块 | 行业板块 |
|------|---------|---------|
| 特性 | 短期热点，波动大 | 长期趋势，波动小 |
| 驱动因素 | 事件/政策/情绪 | 基本面/业绩/周期 |
| 涨停相关性 | 高（涨停驱动概念） | 低（趋势驱动） |
| 采集频率 | 盘中高频（3分钟） | 盘后低频（日级） |
| 核心指标 | 涨停数/连板梯队/龙头股 | 资金流向/成分股表现 |
| 历史数据 | 近30天 | 近1年 |

### 数据模型（已存在，已完善）
- `SectorStrength` - 板块强弱排名（保留）
- `SectorLifecycle` - 板块生命周期状态（含sector_type区分）
- `SectorRotationCalendar` - 轮动日历
- `SectorMainLine` - 主线板块追踪

### 生命周期状态定义
| 状态 | 判定依据 | 交易建议 |
|------|---------|---------|
| **emerging** | 首板2只+, 资金初进, 前日休眠 | 🚀 刚启动 - 重点关注 |
| **accelerating** | 连板3只+, 涨停5只+, 资金3亿+ | ⚡ 加速 - 择机参与 |
| **climax** | 涨停10只+, 龙头5板+, 资金5亿+ | 🔴 高潮 - 谨慎追高 |
| **diverging** | 涨停减少30%, 掉队股出现 | 🟡 分化 - 去弱留强 |
| **declining** | 龙头断板, 批量跌停 | 🟣 退潮 - 回避 |
| **one_day** | 前日首板潮, 今日无持续 | ⚪ 一日游 - 避坑 |
| **dormant** | 无涨停/无资金 | ⚫ 休眠 - 忽略 |

## K线采集Bug修复 + 涨跌幅/振幅计算 + K线因子回填Lifecycle

### 修复3个Bug
1. **行业K线天数Bug**: 注释说250天, 代码实际60天 → 修复为概念60/行业250(各自默认)
2. **涨跌幅/振幅缺失**: AkShare不返回, 采集脚本存None → 自行计算
   - change_pct = (close - prev_close) / prev_close * 100
   - amplitude = (high - low) / prev_close * 100
3. **K线因子未回填Lifecycle**: 模型有字段但没数据 → 采集+分析链路全打通

### 新增计算逻辑(在parse_kline_df中)
- 涨跌幅/振幅: 依赖前一日收盘价
- 均线: MA5/MA10/MA20/MA5成交量
- 趋势指标: trend_state(up/down/sideways/breakout_up/breakout_down)
- 量比: vol_ratio = 当日量/MA5量
- 支撑位: 近20日最低价
- 压力位: 近20日最高价
