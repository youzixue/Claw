#### Tab1: 异动扫描 (重写 — 接入真实数据)

**核心逻辑**: 用腾讯实时27字段 + 同花顺K线技术指标 = 真实异动信号

| 展示项 | 数据来源 | 字段 |
|--------|---------|------|
| 量比异常(>3) | 腾讯[49]量比 | volume_ratio |
| 换手率极端(<0.5%或>15%) | 腾讯[38]换手率 | turnover_rate |
| 5分钟急拉(>3%) | 腾讯[62]5分钟涨跌 | pct_5m |
| 主力大额流入(>成交10%) | 腾讯[50]主力净流入/[37]成交量 | main_net_inflow/volume |
| 突破信号(MA/布林带/前高) | 同花顺K线计算 | MACD金叉/突破MA60/布林带上轨 |
| 涨停封板 | 腾讯[47]涨停价 vs [3]最新价 | is_limit_up |

**表格列**: 代码 | 名称 | 异动类型 | 强度(S/A/B/C) | 关键数值 | 所属板块 | 共振状态 | 操作(→详情)

#### Tab2: 强势排行 (重写 — 基于BullScoreModel + 27字段真数据)

**综合评分维度** (BullScoreModel增强):

| 维度 | 权重 | 数据来源 |
|------|------|---------|
| 动量强度 | 20% | [32]涨跌幅 + [69][70]多周期涨跌 + K线趋势状态 |
| 资金面 | 25% | [50]主力净流入 + 连续N日净流入 + [74]委比 |
| 技术形态 | 20% | MA排列/MACD/KDJ/RSI/布林带位置(从K线算) |
| 估值安全 | 10% | [39]PE_TTM + [46]PB + [64]股息率 |
| 基本面 | 10% | [79]净利润增速 |
| 规模适配 | 5% | [44]流通市值(偏好100-500亿中盘) |
| 活跃度 | 10% | [38]换手率 + [49]量比 |

**输出**: S级(≥85) / A级(≥75) / B级(≥65) / C级(≥55) / D级(<55)
**只显示S/A/B级**, C/D级不推

**表格列**: 排名 | 代码 | 名称 | **综合评分** | 等级 | 动量分 | 资金分 | 技术分 | 估值分 | 板块共振 | 建议(展开)

#### Tab3: 龙头追踪 (保留dragon_head.py + 增强展示)

现有DragonHeadScanner算法不变, 增加展示:

| 新增列 | 来源 |
|--------|------|
| 板块内排名 | dragon_head.rank |
| 板块涨幅对比 | 个股涨幅 vs 板块平均涨幅 |
| 封单金额估算 | 涨停价×挂单量 |
| 连板梯队位置 | 该连板高度的总数量中的排位 |

#### Tab4: 共振分析 ⭐ 新增

**这是板块共振的核心落地**

| 展示项 | 说明 |
|--------|------|
| 强共振列表 | 个股大涨+板块大涨+多股涨停 → 安全追 |
| 弱共振(龙头先锋) | 个股涨+板块微涨+量比放大 → 小仓试探 |
| 独立行情警示 | 个股涨+板块跌+主力流入 → ⚠️需确认原因 |
| 板块拖累抗跌 | 个股平/微涨+板块大跌 → 可能补跌 |
| 每条记录含: 代码/名称/个股涨幅/板块名/板块涨幅/板块涨停数/共振类型/置信度/建议 |

**交互**: 点击行 → 跳转个股详情页, 自动打开"板块共振"tab

#### Tab5: 明日预案 ⭐ 新增

**盘后生成, 基于今日收盘数据+K线技术指标**

| 展示项 | 说明 |
|--------|------|
| 标的代码名称 | 今日收盘状态摘要 |
| 多周期位置 | 10日/20日/半年/1年涨跌幅+所处百分位 |
| 技术信号 | MA排列/MACD/KDJ/布林带/支撑压力位 |
| 资金态度 | 主力连续N日净流入/流出方向 |
| 估值评估 | PE/PB/股息率 vs 行业均值 |
| ▶ **操作方案** | 条件A低吸/条件B追入/条件C观望 |
| ◀ **失效条件** | 夜间利空/外盘暴跌/竞价异常 |
| **止损止盈** | 止损价/目标价/仓位建议 |

**生成时机**: 盘后15:10自动计算, 存入DB, 前端可随时查看

#### Tab6: 实时盯盘 ⭐ 新增 (对应"实时行情观察"场景)

**盘中高频刷新(10s)**, WebSocket推送 + 页面轮询降级

| 区域 | 内容 | 刷新频率 |
|------|------|---------|
| **异动预警列表** | 最新触发异动的股票(按时间倒序) | 10s |
| **市场温度计** | 涨停数/跌停数/封板率/炸板数/市场均价 | 30s |
| **量比TOP10** | 全市场量比最高的10只 | 30s |
| **5分钟涨幅TOP10** | 短期急拉榜 | 1min |
| **主力流入TOP10** | 主力净流入最大 | 1min |
| **委比异常** | 委比>+50%(抢筹)或<-50%(砸盘) | 10s |
| **接近涨停距<2%** | 即将封板监控 | 10s → **飞书推送!** |

**飞书推送规则**:
```
触发条件任一满足即推送:
  1. 量比>5 且 5分钟涨幅>3% 且 主力净流入>0   → "疑似主力拉升"
  2. 委比<-40% 且 成交量>昨日同时段1.5x        → "大单砸盘"
  3. 距涨停价<2% 且 委比>+50%                 → "即将封板"
  4. 换手率>15% 且 振幅>5% 且 涨幅<1%         → "高位放量滞涨"

限频: 同股300秒冷却, 每小时最多30条
格式: 飞书卡片(代码/名称/关键数值/操作建议)
```

#### Tab7: 我的关注 (新增)

用户自选股列表 + 一键添加/删除:
- 显示关注股的实时行情概要(价格/涨跌幅/量比/主力流入)
- 关注股触犯异动规则时**优先推送**
- 支持从其他tab一键添加到关注

| 决策点 | 选择 | 理由 |
|--------|------|------|
| stock_spot刷新方式 | 调度器每30秒全量刷5190只 | 腾讯接口0.08s/100只, 5190只≈5s, 完全可行 |
| K线存储 | 只存原始OHLCV, 指标实时算 | MA/MACD等从原始数据rolling计算, 不存冗余 |
| 五档盘口 | 单独表, 不放spot | 更新频率不同(10s vs 30s), 避免大事务 |
| 共振计算时机 | API请求时实时算(缓存60s) | 数据源都有, 计算轻量(几个比较+聚合) |
| 明日预案生成时机 | 盘后15:10定时任务 | 所有当日数据就绪后一次性生成 |
| WebSocket vs 轮询 | WS为主, 轮询降级 | 前端WS断开自动降级为10s轮询 |
| 前端实时数据 | 不经过DB直推 | 盘中数据走WS/内存缓存, 盘后才落盘持久化 |
