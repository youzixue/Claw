# 第22轮：共享日线因子输入修复（源码验收，未部署）

## 核实与范围

- 旧 `api/v1/factors.compute_factors` 和 `risk/factor_scheduler.compute_and_store_factors` 各自从没有来源/首到证据的 StockDaily 取“最近30条”，未要求请求日真的有行情，也未按确认交易日保留缺口。请求日期可贴在更早末条数据计算的值上。
- 单股入口直接合并 FundFlow 原数值，不验源/版本/三钟/全日完成；批量入口根本不读取资金。同一因子在两个入口的输入不一致。
- 批量入口的 `codes[:100]` 静默截断，却返回 ok、宣称截面计算；没有真正调用截面排名。修复保持原100只运行上限，不擅自扩大计算负载。
- 本轮只改两个计算入口及其共享输入，不能据此解释9/14每笔交易因果。未补造原决策时间、历史因子值或涨停前证据。

## 实现

新增 `backend/app/factors/market_inputs.py`，协议 `factor_formal_daily_inputs_v1`：

1. 复用本地 `expected_index_trade_days`，30个确认会话加1个价格链锚点；缺开市日历失败关闭，不联网。默认截至本地请求时刻已完成的交易日，15:10前不含当日；明确请求非交易日/未来/未收盘日拒绝，不悄悄换日期。沿用研究正式收盘15:10边界，不把它叫供应商实际首到时间。
2. 只读 StockKline 明确叶子，接受原正式来源 ths/tencent_close；复用 `kline_quality_issues` 和 `price_chain_evidence`，原0.011容差不变。未知/异常OHLC、来源、零量停牌、缺/断价格链的整行市场字段未知。缺日保留为对应会话的空行，不跳日拼接。有限窗口在坏日离开依赖区间后可有值；递归指标依赖30行，仍未知。不推断复权原因、不改旧K线。
3. StockDaily/Spot没有回退。StockKline未存振幅，本轮振幅保持未知，不从另一表借值或新增未经验证的公式。
4. FundFlow按同一会话日期合并，复用 `closed_fund_status`：合法来源/版本、源与接收和观察时钟因果/年龄、首次观察不晚于请求截止、源水印至少15:00。最新日行不倒退回填历史；缺失/非法/未来/非收盘资金为None。合格主力流真零保留，细分资金各自缺失仍None；不从主净额反推细分。主净额、细分和成交额沿用元；换手率/涨幅沿用百分数，成交量沿用库存单位，不改源映射。
5. 固定30行输入值SHA、各日问题/价格链/资金时钟、每列可用数与可用因子数用于解释。这个SHA只标识返回计算材料值，不是原始源响应签名，更不是完整因子采证记录。接口返回时没有追加不可变因子表。
6. 每个代码重新读本地日历，避免传入未验证日期列表绕过检查。显式SQL与no_autoflush不隐式提交调用者待写源数据。批量仍是有界逐股研究，不是整个市场同一物理快照/跨股票原子截面。
7. 两入口调用同一loader与原FactorEngine；单股接口保持factors各字段，额外返回input_evidence/available_factor_count，API参数错返回422。批量返回确定性代码顺序、去重后的requested_count、attempted_count、deferred_codes、错误代码及available_factor_values，不再把101只中的前100只称全池成功；调用者可显式处理剩余代码，没有自动续批或训练。
8. 原 FactorStorageService 不修改，仍仅插入尚不存在的旧格式FactorValue；不会覆盖既有值。它不保存这份新输入诊断，也不支持新版本因子/历史可用时间。本轮没有调用生产存储/评估API。

## 边界与交易影响

- 明确 `point_in_time_verified=false`、`promotion_eligible=false`、`automatic_weight_update=false`、`trading_authority=false`。StockKline/FundFlow是读取时的日期投影，历史版本和修订可见性仍未知，旧/新FactorValue都不因此成为PIT仓库。
- 48个注册因子不等于48个可用因子；新闻、基本面、板块、情绪、晋级等逐股上下文未接入此loader，继续未知，不补中性默认值。`compute_cross_section` 的共同kwargs问题及完整前向不可变采证/三模块复用仍未完成。
- 可改变手动研究计算值和覆盖率，合格真实资金与缺口屏蔽会影响后续研究IC的输入池；未改48因子公式、排名、权重、生产策略阈值、持仓退出、风险/撮合/账户、推送、自动晋级或交易入口。
- 30日价格链合格仍不证明完全同复权基础、公司行动原因或真实可成交收益。没有把盘中价格标记收益当T+1成交收益。
- 延续/修复/午后启动、同预算容量与退出时间外研究仍需原决策不可变特征和负对照；本轮是输入基础修复，未产生可晋级研究结论。
