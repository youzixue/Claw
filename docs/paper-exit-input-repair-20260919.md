# 模拟盘退出输入修复（2026-09-19，接续入口与仓位修复）

本轮接续 [入口与加仓修复](paper-entry-repair-20260919.md)，检查退出规则实际读取的参数和行情。修改范围为 `backend/app/api/v1/paper.py` 的退出上下文、走弱证据计数及一处 T 回补调用，以及 `backend/app/paper/account_policy.py` 的执行版本快照。未修改调度器、前端、数据库表结构、资金配置或持仓记录。

## 确认并修复的问题

1. **冻结阈值未贯穿证据计数。** 持仓已经冻结 `volume_negative_ratio`，但走弱证据、开盘止损豁免和板块退潮佐证仍读取全局 `PAPER_AUTO_VOLUME_NEGATIVE_RATIO`。例如持仓阈值为 3、全局为 1.2，量比 2 会被错误计为放量；全局高于持仓阈值时又会漏计。现在整条短线退出判断使用同一份持仓参数，计数与日志说明一致。
2. **平盘与缺数据被日线替换。** 原 `spot.change_pct or kline.change_pct` 会把有效的 0% 当成缺失值；开高低缺失也会借用其他时点的日线。现在涨跌幅保留 0%，盘中开高低、VWAP 缺失或非正值保持缺失，不再用日线制造弱势形态。日内位置只在价格落于有效高低区间时计算。
3. **缺失实时量比时混入另一指标。** 原实现把末根日成交量除以前五日均量当成实时量比，末根还可能是昨日或后来覆盖的日终数据。现在只消费当轮报价量比；缺失/非有限/负值不提供“放量”证据，0 则保留为有效数值。
4. **MA 未限制决策日期。** 原查询直接取最新 21 根日线，历史决策可能读到当日日终或未来日线，实时也可能使用滞后的盘中日线。现在只取决策日前日线，在当前报价通过现有时钟与有效性检查时，以该报价作为当日唯一价格计算 MA5/10/20。仍使用 N 项算术平均；窗口含无效收盘价时保持未知，不删掉坏值后拿更早日期补足。无有效当前报价时仅保留前日均线用于诊断，交易提交继续由实时行情门槛拦截。

这些是可复现的代码缺陷，但不能据此断言它们就是 9 月 18 日每一笔卖飞的实际原因。尤其冻结量比阈值与全局阈值相等时，不会产生该项差异。
