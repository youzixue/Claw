### 已修复的工程边界

1. **来源故障隔离**：只允许本源同轮完整健康回执参与分配。一个来源失败不再自动阻断其他健康来源；部分故障仍标记degraded并保留原因，不伪装整轮完成。合法空池与扫描故障分开。
2. **真实锁后时钟**：新买单在SQLite写锁内重新核验实际接受时点、实时上下文和持久报价轮；不能用锁前旧时钟跨过120秒，也不能以已在接受前出现的报价冒充“下一轮”。拒绝时保留风险审计，不产生可执行预约或成交。
3. **费用边界**：预算预留最坏分片费用，但实际账本只扣真实成交佣金。例如10元股票初始自动900股，100/100/700三次成交实际佣金15元，而非把45元预约当已发生费用。
4. **真实成交状态归因**：源信号ID绑定原委托；每片成交必须由TradeFill的broker_trade_id关联真实PaperTradeLog主键，再核账户/股票/轮次/日期/价格/数量/版本。已纠正误用源信号ID匹配分片账本导致状态未知的问题。
5. **重复钱包**：不得任取同名账户。共享钱包异常时停止授权或显示未知，不借用来源账户的成交。

这些场景已有隔离环境下的真实执行实现测试（含10项锁内风控、部分成交、幂等、回滚、T+1与退出），不等于生产自然成交已验收。
