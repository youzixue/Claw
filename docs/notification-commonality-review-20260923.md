# 9/23推送扩样复盘：追高、弱修复和确认后持续性

## 结论

**扩大样本后，确有“短时拉升后才确认”的负标记集中现象，但它不是唯一问题，也不能用一个统一阈值解决。** 这次不只看旭光电子和中晶科技：重新计算9/23全部原12户56条通知入口、C3全部28条；追加9/22原户55条作为描述性对照。未发送、拒绝、过期、正例与unknown均保留；已停用旧组合单独隔离，不混算。

研究于9/24凌晨进行，最近完整收盘日为9/23。下文正负指“提醒参考价到当天终场价”的标记变化，**不是用户真实成交、模拟盘已实现盈亏或可兑现的T+1收益**。

## 3. 共同点二：靠近均价线，也可能只是弱修复

- 鼎际得确认价仅比VWAP高0.059%，仍到终场−3.902%；旭光电子只有0.298%，仍回落。**低溢价不等于低风险启动。**
- 原户56条中55条当时累计low曾低于昨收；但只有32条在当前合法连续归档段观察到最近5分钟的双线收复。
- C3 28条中26条累计low曾在水下，只有2条在当前段观察到最近5分钟收复。不能把“当天曾在水下、现在在线上”统一叫“刚启动”。没有观察到穿越也不等于没有发生，左截断和午休/断流必须保留。
- 现有原户确认更偏当前站上昨收/VWAP、量比/盘口/相对强度达标；持续60秒不证明未来能继续上攻，也不证明首次收复。
- 前日日K分组：原户“均线上阴线整理”23条中4正19负，“缩量小实体”9条中5正4负；但C3阴线整理为6正5负。**同一K线标签跨路线表现不同，不能照涨停赢家形态统一买入。** 84条中7条历史价格链冲突已留unknown，没有硬算形态。

**算法方向：增加有时间锚的修复过程，而不是再堆静态指标。** 复用已有峰谷、回踩、失效状态，区分首次有效收复、反复穿越和后续修复；保留原路线身份，不把A/C2/F2/C3全换成A2。A2当日已发3条也全为负标记，故“首次回踩”同样不是免验证的答案。

- 冠石科技 C3：后约5分钟+0.514%，到终场−0.637%。

这些是后验诊断，**不能拿“5分钟后会跌”回填入场过滤，也不能建议A股当天新买后五分钟止盈**。T+1决定算法必须评估隔夜可退出表现，而不只是抓住几十秒上冲。

C3的短时急拉问题与C2不同：其12条已发中没有前5分钟>2%的样本，套用该过滤没有作用。C3负组8条的VWAP溢价均值约1.304%，正组3条约0.453%，但低溢价仍有输家、高溢价样本也少；需要独立研究板块扩散、回踩承接和持续性，不能凭此设一个新硬门。

## 5. 发送提速不是全部答案

原户45条在通知观察/复验→发送回执之间，归档可见价平均变化−0.024%，C3为+0.038%，中位均为0；57条已发中38条两端复用了同一源时刻报价。**零变化仅表示离散档案可见价未换，不能证明实时价格没变或可以同价成交。** 约30秒采样会漏掉区间内往返，API回执也不代表用户已读。

这不足以断言延迟无害，但**不支持“全部亏损都是飞书慢了几十秒，提前发就能解决”**。早观察、正式确认、当前可执行和模拟成交必须分层；提速不应靠缩短原确认、刷新TTL或发送已失效机会。

## 6. 离线实验决定与下一步

**本次可交付结论：不晋级任何新交易规则，明确优先研究的三个方向。**

1. **确认价伸展控制**：原候选不变，单独比较伸展后等待回踩与原连续确认。禁止用本日2%作为直接生产值；记录排除赢家/未回踩强股。
2. **修复过程识别**：复用既有状态机，研究首段/后续修复、承接低点和重新转强，不以累计low代替新启动锚。仅早观察可以提前，不冒充已确认买点。
3. **C3分形态持续性验证**：强势推进、整理突破、水下修复分别保留分母，比较确认后的失效及T+1结果，不强套C2规则、不把研究推送接单。

详细候选实验、反例、代码复用点和晋级要求见 `outputs/notification_commonality_20260923/HYPOTHESES.md`。新策略按未来交易日walk-forward验证，不随机切股票，不放宽原仓位、风险、TTL或交易资格。两天只能揭示问题和否决简单捷径，不能证明长期盈利。
