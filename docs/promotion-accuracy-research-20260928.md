# 晋级命中率：算法对照与可验证边界（2026-09-28）

> 9/29补充：后续发现本报告使用的历史v2面板在候选选择前排除了部分T+1缺失/歧义样本，存在事后筛选。本报告与原冻结文件保留，但13.67%等数值不能作为干净候选集的效果证明；后续以修复后的v3未知保留实验为准，详见 `docs/promotion-recall-direction-20260929.md`。未发生生产模型晋级。

## 本轮问题与结论边界

用户要求不止换源，还要处理首板和次日上涨命中率。本轮为盘后离线研究，不接管交易、不替换生产 Champion，不承诺80%。

源码显示两个不同目标不能靠一个显示概率解决：

- `promotion.py::_first_board_rank_key`：legacy正式主榜先看可交易身份、手写历史证据分，再看其他项；显示首板概率不是第一排序项。抬高显示概率不等于选到更多真首板。
- `_first_board_temporal_probability`：固定时序logit与路线后验混合；未部署挑战者。
- `_apply_promotion_learning_to_candidates`：上涨概率主要是路线历史收涨率及小残差，不是已部署的独立方向分类器。
- 这些是源码事实；“近期风格变化使旧训练样本拖累排序”只是本轮可证伪假设。

## 1. 本轮实现

仅扩展现有研究链，不创建平行生产模型：

1. `walk_forward.py`增加可选`train_window_days`，按独立交易日取最近窗口，窗口**包含拟合期和校准尾窗**。默认不传仍为扩展训练。验证日期、候选和固定Top-K不因窗口缩短而改变。
2. `training.py`让最终产物采用与走步验证相同的窗口，保存窗口配置和真实拟合起止，避免“用滚动窗口验收、却用全历史发布”的不一致。
3. `direction.py`和原训练CLI透传该参数；方向研究仍禁止persist/自动晋级。普通历史面板产物仍最多pretrained。
4. 修复拟合窗口报告依赖输入首尾顺序的问题：日期边界取真实min/max，不改变拟合数值。
5. 修复上轮源模型新增列引出的只读研究崩溃：`ledger_dataset.py`只投影标签审计实际需要的5个涨停池字段。未迁移库不再因无关`source_version`报错；不补迁移、不降低封存真值/质量检查。

生产权重、Top12、召回准入、风控、订单和前端均未改。研究配置不意味着已有模型或服务发布。

## 2. 独立上涨模型：真实材料盘点

在北京时间2026-09-28 23:34:34截止，只读事务扫描8/31至9/28的20:00正式批次：

- 加载307次尝试，按原规则选19个日期最新尝试，不回退失败前旧成功。
- 合格方向训练样本为0，状态`insufficient_evidence`，不是0%上涨命中率。
- 最先失败原因：10日缺少/无效冻结方向合同、2日质量门未通过、2日最新批次未完成、2日结局质量不完整、3日日历缺口。
- 后续身份/封存材料门尚未到达，不能认为只修以上原因就必能训练。

## 3. 预先指定的首板算法实验

唯一假设：**最近60个交易日滚动训练比全部历史扩展训练更适应近期风格**。

复用现有NumPy logit、Platt、特征提取及历史宽候选生成器，其他参数保持不变：

- 历史窗口160交易日、每日450候选，截止2026-09-24；
- 初始训练60日，校准尾窗10日，验证10日/步长10日；
- 同一物化候选集，只读一次数据库，再压缩冻结研究特征与标签；
- 对比AP、Brier、ECE、固定Top5/12/30精度/召回、全市场候选召回及风格分层；
- Top12增益做500次整交易日配对bootstrap，固定seed=0；
- 失败fold、候选/标签不一致必须报告，不通过选日/缩名单美化结果。

程序：`outputs/promotion_accuracy_20260928/compare_training_windows.py`。
研究面板只冻结必要特征，不复制36GB业务数据库；这是历史预训练材料，**不是生产冻结快照或历史首知认证**。继承原历史数据的ST、复权、缺失值与日期假设，不能直接晋级或声称实盘命中改善。

### 结果：拒绝滚动60日替换

同一72000条/160日研究面板，验证期2026-05-06至2026-09-23，100日、45000候选、1716个池内正例；10折均完成，双方验证候选/标签完全相同。

| 指标 | 扩展训练 | 滚动60日 |
|---|---:|---:|
| Top12首板精度 | 164/1200 = 13.6667% | 160/1200 = 13.3333% |
| Top5精度 | 16.6% | 15.6% |
| Top30精度 | 11.0% | 11.4% |
| AP | 0.084619 | 0.082710 |
| Brier（低好） | 0.036182 | 0.036244 |
| ECE（低好） | 0.004572 | 0.005305 |
| Top12全市场召回 | 2.9678% | 2.8954% |

Top12精度差为−0.3333个百分点；整日配对bootstrap中央90%区间为[−1.1667，+0.5000]个百分点，没有可靠改善证据。四个风格的AP都下降、Brier都升高，虽部分差异在原风格宽容区间内，也不能据此宣称稳健提升。Top30略有进步不抵消主榜/校准失败。原门禁明确在AP、Top12和ECE三项拒绝。

全160日研究面板宽池仅覆盖2643/8194 = **32.2553%**的历史有效真首板；这是候选预筛上限，不是生产主榜命中率。仅换排序模型无法找回池外目标，后续应先检验分层召回覆盖，而非继续盲调概率/重训频率。

**没有选更短/更长窗口继续扫参挑赢家；没有把本次结果晋级或连接交易。**

## 4. 修复、未修复与后续顺序

- **已修复**：只读研究入口与未迁移库兼容；训练窗口边界元数据；增加可复用的受控滚动训练实验能力，验收/最终产物窗口一致。
- **已检验并否定**：在本次固定研究材料上，“最近60日训练优于扩展训练”没有成立。
- **尚未实现**：生产首板/上涨命中率可验证提高。当前Champion、排序权重和所有风控保持原样，原页面问题不能说已经解决。
- **优先后续**：以腾讯/问财真实新批次恢复完整冻结材料；检查首板分层召回漏失，再以独立方向标签训练排序。旧缺失的首知/冻结证据不得倒填，不能保证修复源后当天即可获得合格的多日训练集。
