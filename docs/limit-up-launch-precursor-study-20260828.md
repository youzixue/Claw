# 涨停池启动前特征研究（2026-08-28）

## 研究问题

研究主板非 ST 个股在首次涨停前可见的消息面、个股资金、日 K 线与板块形态，并寻找“低位板块刚启动”而不是“单纯价格很低”的稳定相似特征。目标同时覆盖：

1. 次日首次涨停（低基准率事件）；
2. 次日收涨（方向事件）；
3. 次日强涨（最高或收盘涨幅达到 5%）。

## 无未来函数口径

- 预测事件日为 T，K 线、资金、板块只读取 `trade_date <= T-1`。
- 正样本：沪深主板、非 ST、T 日在涨停池且 T-1 不在涨停池的严格首板。
- 对照：同一 T 日按稳定哈希抽取的主板未涨停股票，默认每个正样本配 5 个对照。
- 上一收盘消息：只取 T-1 20:00 前 72 小时内明确关联个股代码的信息。
- 隔夜消息：T-1 20:00 至 T 09:25 独立统计，绝不回填到上一收盘特征。
- 结果标签只来自 T 日 K 线，不能参与任何特征生成。

cd backend
python3 scripts/analyze_limit_up_precursors.py \

  --end-date 2026-08-28 \

## 第一轮日期匹配研究结论

严格主板首板共 5,205 个事件，100 个交易日；其中 4,937 个具有完整 120 根启动前日 K。以下 LR 为“正样本特征覆盖率 / 同日对照覆盖率”，用于判断方向，不直接当成概率。

### K 线与个股资金

| 特征 | 正样本覆盖 | 对照覆盖 | LR | 结论 |
|---|---:|---:|---:|---|
| 120 日位置 ≤35% | 51.9% | 70.2% | 0.740 | 绝对低位是负向/噪声，不应直接加分 |
| 低位且近 30 日无涨停 | 30.4% | 56.8% | 0.536 | “无记忆低位”不能单独入正式池 |
| 低位温和修复 | 15.0% | 34.5% | 0.435 | 缺少量价/板块确认时仍是大噪声 |
| 单日量能预热 | 9.38% | 8.74% | 1.073 | 只有很弱的增益 |
| T-1 主力资金为正 | 33.3% | 30.8% | 1.082 | 单日资金区分度很小 |
| 最近 3 日至少 2 日主力占比为正 | 30.0% | 26.8% | 1.119 | 多日持续优于单日 |
| 最近 3 日主力净流入占比合计 ≥3% | 25.8% | 21.2% | **1.217** | 稳定但应保守使用的资金预热特征 |

正样本中位数相对对照：120 日位置 0.330 vs 0.203、20 日收益 +1.64% vs -2.91%、T-1/20 日量比 0.984 vs 0.888、换手 4.04% vs 1.83%、距 MA20 +0.53% vs -1.37%。真正有用的不是最低，而是已经修复并重新活跃。

### 主营行业与宽泛概念

全概念/行业取“当日最强映射”只有温和增益，且容易被一个股票对应几十个热门概念稀释。主营 `industry` 独立口径更稳定：

| 主营行业特征 | LR |
|---|---:|
| 行业强度 ≥55 | 1.212 |
| 行业涨停宽度 ≥2 | 1.204 |
| 行业低位轮动 | 1.245 |
| 行业生命周期 emerging | 1.212 |
| 中低位个股 + 行业低位轮动 + 量比 0.75~2.5 + 换手 ≥1.5% | **1.295** |

该组合覆盖率约 1.72%，适合做高置信度稀疏证据，不适合替代主候选召回。宽泛概念只有在直接消息、涨停原因或竞价集群明确归因时才用于确认。

### 时间外留出验证

脚本只用前 67 个事件日（2026-04-07～2026-07-20）学习布尔特征 log-lift，再在完全未参与训练的后 29 日（2026-07-21～2026-08-28，8,994 样本）验证：

| 排序 | 训练目标/AUC | Top20%首板率/lift | Top20%上涨率/lift | Top20%强涨率/lift |
|---|---:|---:|---:|---:|
| 只按绝对低位 | 首板 / 0.483 | 14.8% / 0.889 | 66.9% / 1.018 | 20.0% / 0.838 |
| 上一收盘首板证据 | 首板 / **0.612** | **23.7% / 1.424** | 64.7% / 0.985 | **34.6% / 1.448** |
| 首板证据+独立隔夜消息 | 首板 / **0.615** | **24.6% / 1.473** | 66.0% / 1.005 | **35.4% / 1.483** |
| 独立普通收涨权重 | 收涨 / 0.512 | 23.7% / 1.424 | **66.3% / 1.009** | 33.8% / 1.414 |
| 普通收涨权重+隔夜消息 | 收涨 / 0.517 | 24.3% / 1.460 | **66.7% / 1.016** | 34.2% / 1.432 |
| 独立强涨权重 | 强涨 / **0.632** | 23.9% / 1.437 | 65.0% / 0.991 | **34.8% / 1.455** |

这说明新证据能明显改善“首板/强涨”排序，但普通收涨只有很小的时间外增益（AUC 0.512～0.517、Top20% lift 1.009～1.016）。因此方向概率只允许极小、可为负的独立微调，不能把首板 LR 机械搬过去；隔夜消息也只进入 09:25 后的独立快照。

## 落地算法

特征版本：`launch_precursors_v20260828_2_outcome_split`；预测模型版本：`promotion_v20260828_25_asof_split`。

### 1. 中低位修复画像

`launch_profile_ready` 同时要求：

- 120 日位置在 12%~58%，排除极深低位继续下跌；
- 5 日收益 -4%~10%，20 日收益 -3%~24%；
- 收盘相对 MA20 在 -2.5%~12%；
- T-1 成交量 / 前 20 日均量在 0.75~2.50；
- 换手率至少 1.5%。

画像只代表“有启动准备”，不代表会涨停。

### 2. 三日资金预热

`funding_preheat_ready` 要求最近三个可见交易日：

- 主力净流入占比合计至少 3%；
- 至少两日为正；
- 单日脉冲不能替代多日持续。

连续三日负流入且合计不高于 -8% 标记为资金流出风险并小幅降权。

### 3. 主营行业点火

独立读取 `industry` 映射，满足任一条件：

- 行业低位轮动；
- 行业强度 ≥55、涨停宽度 ≥2，且活跃不超过 3 日/处于 emerging 或强度明显抬升；
- emerging 行业强度 ≥50、至少 1 只归因涨停。

### 4. 低位行业启动组合

`low_base_sector_ignition_ready = launch_profile_ready + primary_industry_ignition_ready`。

若再有三日资金预热或直接高质量公司消息，则标记 `low_base_sector_ignition_confirmed`。该组合：

- 首板排序只增加约 1~3 分，并使用首板 LR；
- 普通收涨不再使用首板 LR，只有量价、持续资金和直接消息的对应上涨 lift 可施加 -0.12～0.18 的有界 log-odds 微调；
- 强涨使用独立强涨 lift，可施加 -0.18～0.32 的有界微调；
- 始终保留 `prediction_only` 属性；
- 绝不绕过 `trade_ready`、竞价完整性、盘口承接和风控闸门。

### 5. 消息聚合与时效

直接个股消息新增上一收盘/隔夜数量、高影响数量、硬事件数量、重复消息和信息阶段。显式 `news_end_time` 改为硬截止，且按 15:10 / 20:00 / 次交易日 09:25 / 09:35 快照上下文固定时钟；即使任务迟到重跑，也不能把后续消息回填进较早快照。

## 失效条件

- 只因 120 日位置很低就扩池；
- 只看单日主力净流入；
- 从几十个泛概念中机械挑最热概念当主营行业；
- 把板块消息扩散到所有成分股并赋予公司级消息权重；
- 把上涨概率、涨停概率与交易可执行性混为同一指标；
- 在 T-1 收盘快照中使用 T 日 09:25 前才出现的隔夜消息。

## 验证要求

- 纯特征单元测试覆盖绝对低位拒绝、三日资金持续、行业/个股组合和方向概率微调。
- 新闻测试覆盖高影响/重复事件聚合和显式 as-of 硬截止。
- 晋级 API 测试覆盖资金不穿越锚点日、主营行业独立选择、预测与执行闸门分离。
- 全量研究输出保存 JSON/Markdown，模型继续按新版本独立积累正式 schedule 样本，再由 beta-binomial 路由后验校准。
