# 板块生命周期决策表

适合前端、产品、运营直接查看的简版口径。

## 判定优先级

`高潮 -> 退潮 -> 分化 -> 加速中 -> 刚启动 -> 一日游 -> 休眠`

## 决策表

| 状态 | 主要特征 | 核心字段 | 参考阈值 | 页面说明 |
| --- | --- | --- | --- | --- |
| 高潮 | 批量涨停，高标很高，板块最拥挤 | 涨停家数、连板家数、最高板、资金流 | `涨停>=10`、`连板>=5`、`最高板>=5`、`资金流>5亿` | 情绪最强，但分化风险最高 |
| 退潮 | 龙头断板或梯队瓦解，资金明显流出 | 前一日状态、跌停/回撤、资金流、日K趋势 | 前一日为强势状态，且 `资金流<-5亿` 或 `跌破MA20` 或 `梯队归零` | 结构破坏，回避为主 |
| 分化 | 龙头还在，后排开始掉队 | 前一日状态、涨停衰减、最高板、结构完整度 | 前一日为 `加速/高潮`，今日 `涨停<5` 或 `最高板<4` | 强转弱过渡，重龙头轻跟风 |
| 加速中 | 连板梯队形成，资金持续流入 | 涨停家数、连板家数、最高板、活跃天数、资金流 | `涨停>=5`、`连板>=3`、`最高板>=3`、`连续活跃>=2天`、`资金流>3亿` | 主升阶段，关注核心龙头 |
| 刚启动 | 板块开始活跃，首板扩散但结构未成型 | 涨停家数、资金流、短趋势 | `涨停2-4只`，或 `1只涨停+资金/趋势转强` | 可关注，但先看次日持续性 |
| 一日游 | 昨日启动，今日无承接无扩散 | 前一日状态、次日涨停、资金流 | 前一日 `刚启动`，今日 `涨停<=1`、`资金流<=0` | 启动失败，避免追高 |
| 休眠 | 无涨停、无资金、无趋势 | 涨停家数、资金流、活跃天数 | `涨停=0`、`资金流<=0`、`活跃天数=0` | 暂无参与价值，等待信号 |

## 维度总览

| 维度 | 现在是否应纳入 | 用途 |
| --- | --- | --- |
| 涨停家数 | 是 | 启动、加速、高潮的第一主维度 |
| 连板家数 / 最高板 | 是 | 判断梯队结构与龙头强度 |
| 当日资金净流入 | 是 | 判断是否有真实资金驱动 |
| 近3日资金流 | 是 | 判断持续性，不只看单日脉冲 |
| 前一日状态 | 是 | 判断分化、退潮、一日游必须依赖 |
| 板块日K趋势 / MA5 / MA20 | 是 | 确认假启动、分化、退潮 |
| 炸板率 / 晋级率 / 昨日涨停溢价 | 强烈建议 | 让分化、退潮、一日游更接近实盘 |

## 一句话版本

**板块生命周期 = 涨停梯队 + 龙头高度 + 资金流 + 历史状态 + 日K趋势确认。**
