## 2. 额度需要分账户对照，不支持一刀切“下午留一格”

53条buy_signal最终归类：10成交、37容量受限、3撤单、2风控阻断、1不足一手。容量日志混合“日开仓数或最大持仓数”，不是37次全部仅日额度不足；不能直接解释为撤单把额度永久吃掉。

- 下午6条信号均容量受限：相对信号价至收盘 **3涨、2跌、1平**；这是价格标记，不是可成交净收益。
- C2占其中5条，**2涨2跌1平**，信号至收盘等权平均约+0.0066%；A/default有1条正向，A2没有下午buy_signal。不能因为普涨，就断言给所有账户留午后额度一定更好。
- C2实际第二笔上午信号为002213（09:42:38、29.61），其信号至收盘-0.1013%；下午首条容量信号603956（13:04:38、7.20）标记+0.2778%。这只是一个**替代候选配对**，缺少“改变上午成交后完整账户状态”和当时可成交深度，不能将两者相减当增益。
- A2实际第二笔000520的信号至收盘为+0.939%，其后没有下午buy_signal。机械保留一格可能闲置额度并放弃已有正向样本。也不能用今日结果事后为不同账户挑最优配额。
- 原撤单会释放活动委托的预留资金/代码，不能等同于永久日开仓消耗；仍应把已成交数、活动预留和日开仓/最大持仓两个原因分开观测。

**预先约定的影子对照：** 原方案为基线；只在原每日上限≥2的账户比较“上午最多原上限−1，13:00释放保留1格”的固定方案。不增加全天上限、仓位或现金，不给候选补授权，不改变原同路线优先级。全量记录上午被延后、下午未用额度、真实盘口不可成交、错失赢家与避开的输家。当前仅提出实验，不在实盘/模拟盘实施。

## 3. 确认消费：多数约一轮，确有长尾，但需扣清开盘等待含义

用**完全相同event_key**关联473个冻结confirmed与当日执行日志，禁止只凭同股票名称/代码硬拼。A2/B2/C2共77个均能找到执行证据；C3另396个本就采证、不连接交易。A2旧规则快照缺少同名connected字段，保留unknown，不能当false；实际连接由匹配日志证明。

09:35后仍有 **7个>120秒长尾**：C2五个、A2两个，集中在09:42、09:59及13:04的消费轮。首次消费已出现盘口失衡、漂移超限、原确认区间失效或容量限制。时间相关不证明全部由预测任务拖慢，也不证明更快消费必能盈利；应在下一交易日分别记录确认提交钟、消费者开始钟、决策轮次源钟、风控结束钟和成交轮次。

**对照方向：** 优先验证性能补丁上线后消费长尾是否缩短；再做消费者及时唤醒/重任务隔离的离线对照，保持候选排序、原720秒有效期、漂移阈值、身份/行情门以及下一健康轮次五档撮合完全不变。不能通过延长有效期或放宽漂移，把延迟变成追价许可。

## 4. 验收准则与保留风险

- 先冻结分层与额度方案，避免看完当天结果再拟合规则；至少跨20个独立交易日、保留全部confirmed和失败分母，按市场环境/账户配对评价，不把同股多轮日志计成独立样本。
- 除覆盖率与消费P90/P99，还看拒绝原因、无法成交率、资金闲置、费用后收益、T+1次日开盘/可退出时点及不利波动。缺少源时钟/深度/次日行情时记unknown，不补零、不借收盘价假成交。
