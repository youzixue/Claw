# 九月A—F及全部次策略复盘：有买点，为什么仍亏损？

## 1. 先回答问题

**你说得对：A—F、A2—F2本来就有各自的模式与买点，不应再另造一套通用形态，也不能用内蒙新华今天跌停解释整月亏损。**

本次核对2026-09-01至09-28，19个交易日、12个独立模拟账户的现存账本、实际成交版本和既有执行代码。结论是：

1. **11户亏、D户零成交持平，亏损确实存在。** 现存225笔买卖记录、98个完整清仓周期；九月已实现经济净损益 **−11,315.25元**，账面净浮亏 **−482.04元**。
2. **不是12套当前模式都得到同样的失败结论。** C2有持续性弱表现；B2大部分历史亏损来自月初旧版本隔离退出；D/D2现行模式没有足够成交；E/F系列样本很少但尾部损失明显。
3. **首要问题不是“没有VWAP、没有回踩、没有模式”**，而是部分模式定义与实际放行不一致、已确认形态缺少净收益优势、名义止损不能覆盖T+1尾部，以及历史版本与执行故障混在一张成绩单。
4. **不能把问题全推给熊市。** 9/16、18、21普涨/修复日入场且截至28日已清仓的21个周期，4赢17亏、净−3,331.18元。但这些交易多在后续交易日退出，不能将其当作同日跑输市场的alpha检验。

本报告仅研究；没有修改策略参数、生产代码、数据库、订单、风控或服务。

## 4. 真正需要区分的亏损机制

### 4.1 有买点不等于有正期望：C2证据最突出

C2不是随意追涨：当前原代码已有低板记忆、调整天数、弱开/下探、收复零轴/VWAP、相对强度、量比、盘口、VWAP斜率及持续确认。

但是：
- 27个完整周期仅4赢23亏，净实现−3,168.90元；平均赢254.94、平均亏182.12，盈利因子0.2435。
- 在这一样本盈亏幅度下，盈亏平衡胜率约41.67%，实际仅14.81%。这是样本描述，不是下一阶段预测阈值。
- 去掉月初legacy及v3后，**9/8起v4入场的23个完整周期仍只有3赢、净−3,103.89元**。不能全部甩给月初旧单。
- 按买前已经生成且可见的市场状态分层，观察到的六类状态各组净收益都为负；小样本、跨版本，不足做显著性结论，但不支持“只加一个退潮禁买就解决”。
- 9/28中电鑫龙、浙江正特已有约60秒/3帧确认，买入时略高于VWAP，随后多数归档帧低于VWAP。此处是**确认后的持续性失败**，不是“程序没有模式买点”。今日两笔仍为开放仓，未混进27个已平周期。

应验证的单一假设：原“收复”确认是否主要识别了短暂反抽，而非调整后的新启动。沿现有候选和确认事件比较，不新增平行选股器、不用今日收盘形态回填买点。

### 4.2 A/A2与B：不能只优化胜率

- A：胜率50%，平均赢80.47、平均亏120.61；当前幅度下需约59.98%才平衡。样本内亏损不是单纯“选中次数太少”。
- B：胜率60%，平均赢118.75、平均亏358.80；当前幅度下平衡点约75.13%。**赢多次也能被少数大亏覆盖。** 但B九月后段新版本仅一个已平周期、净+62.66，不能把旧损失全归给新版本。
- A2：18周期8赢10亏，平均赢358.24、平均亏325.80，盈利因子0.8797；比C2更接近平衡。9/21买入招商南油、凤凰航运两个完整周期合计−1,023.34，不能只盯此前赢家。
- 全账户已付费1,715.73，占存储亏损14.54%。成本重要，但不是主要亏损的全部。A费用218相对亏281、A2费用290.08相对亏307.13较敏感；这不意味着免手续费就有可部署优势。

应分开检查：入场后可兑现收益空间、成交延迟、按原模式定义的退出、少数大亏及费用。不得为了提高胜率扩大止损或取消硬风险。

### 4.3 B2：历史重亏不等于当前版本同样重亏

- 月初两笔legacy完整周期合计−1,600.22元，其中开开实业−1,347.59元；原记录明确涉及旧版/未标版本仓位隔离退出。
- 9/8起入场的17个已平周期合计−196.41元，仍亏，但与全账−1,796.63的诊断不同。
- 中旬一个版本曾盈利，晚段又出现亏损。不得倒选盈利版本，也不能把隔离退出当当前正常模式卖点。

优先按真实版本复核剩余弱优势及退出匹配，不照抄C2整改。

### 4.4 E/E2：发现可核实的模式语义缺口

9/28两户都买入泰慕士200股、31.86元。当日价格、开高低、VWAP均31.86，较昨收−10%；这两笔当天买后价格没有再跌，只各产生5元买费，**不能写成买后亏10%**。

当前原执行链的事实（paper.py 6053–6126、6199–6208）：
1. 入场涨幅只设上界，没有负涨幅下界。
2. price>=VWAP以及从日高回撤检查，在“一价跌停”时分别以相等、回撤0通过。
3. “曾开板回封”只在当前涨停且需要排队的分支核查。
4. E2的`e2_strong_reseal`按账户名直接赋值，并非由真实回封路径生成。

所以，**有VWAP/确认门，也可能放行与强势回封语义不符的状态**。这是模式边界和标签证据问题；未发现买卖方向颠倒，跌停有卖盘时买入也不等于虚假成交。不能替作者推断“本就有意做一字跌停抄底”。

先在原函数内让低位接力、负开修复、实际回封、一价跌停状态可区分，标签与真实证据一致；未满足模式证据不能标记该模式成立。新增排除条件能否改善收益则另做全样本前向验证，不能从这两笔尚未了结的仓位宣布盈利改善。

### 4.5 止损、退出与连续模拟不能混为一谈

- E2锡华科技9/21买入26元，已有约60秒/3帧确认；当日价格跌破冻结止损24.42时可卖数量为0，触发T+1限制。次日完整周期净−424.79元。**止损线不是当日保证损失上限。**
- A豫能控股的退出还有9/23旧减仓单阻塞全退的专项证据，之后已发布修补；本次最终净−439.24。不能把所有亏损差额归给该故障，更不能将后续补丁视为已经避免的历史损失。
- B/C/D及B2/C2/D2等实际共用短线退出梯级；模式不同不表示退出完全独立。A2/E/E2/F/F2走另一持有期梯级。页面描述也不完全等于实际分支，机制报告记录了MA20文案和高标专项配置未直接消费等问题。
- 连续模拟当前明确“不按历史回撤停用、市场状态只分层记录”，同时保留必要数据、资格、现金、仓位、T+1、盘口等风控。这是持续实验政策，不是无风控，也不是已被证明能赚钱的产品承诺。

修订重点应是**买前T+1尾部预算、模式与退出匹配、真实可成交路径及调用一致性**；不是增加一个已存在的止损开关，也不是回看收盘后认定“晚卖一定更好”。

## 5. 市场、资金、消息与执行：能解释到哪一步

### 市场不是连续同一种状态

18个已有收盘regime日（每天仅取最新快照）中：退潮6、板块轮动5、个股主升3、修复2、普涨趋势1、高标投机1；9/28收盘regime尚未在本次接口冻结中出现，不自行补标签。9/1样本3244，之后约5200；部分标签置信度仅0.42—0.55，不当作确定真值。

我们另按**as_of_at和created_at均不晚于入场时刻**连接此前最新已知状态，不能把当日收盘分类当早盘可见特征：
- C2买前risk_off组8周期，1赢7亏、−563.06；recovery组4周期全亏、−700.22。
- A2、B2买前risk_off组却分别净+1,052.77、+2,346.02，各只有4周期。

因此统一退潮禁买会同时删掉赢家；反过来“专买退潮”也不成立。上述只是时间可见性满足的关联分组，不证明当时策略读了该字段，更不是因果收益。

### 数据缺失不能伪装成资金流零或消息无催化

- 市场情绪日表9/7—14多个交易日主力资金0对应覆盖0%；9/15—17、9/23为不可用/null，不能解读为真实没有流入。
- 资金表月初来源/时钟不完整，9/3—4为东财，9/9起为腾讯版本；9/7—8本次日表缺行。混合来源不能直接当同口径资金因子样本。
- 早月缺逐轮归档，9/23下午归档覆盖中断；9/28涨停池和消息覆盖不完整。日表最后状态不自动等于每笔买入时的状态。
- A/B/C/D对必要情绪/资金证据与E/F、部分次策略的价量路径要求不同，数据故障可能改变有效机会供给；须按各自合同核查，不宜把所有策略强行同化。
- 本次没有恢复全月每笔入场前已公开消息和当时版本的基本面快照，因此**不把利润增长、资金净流入或事后新闻硬贴为涨跌原因**。若进一步做个股因果研究，必须补首次发布时间、观察时间、候选证据和来源一致性。

### 漏买与亏损用同一流程分母，而不是只看收盘赢家

复用现有链路：有效行情/历史→候选池→模式触发→持续确认→执行复验/风控→委托→成交→T+1可卖→退出。

分别记录未覆盖、未入池、模式不成立、确认失效、容量不足、数据阻断、不可成交；`blocked`批次数不是漏掉股票数。涨停股可能在涨停之后才入候选；预测“次日晋级”的概率也不能用当日上涨直接评分。被拦截样本须保留赢家和输家，不能只挑博迈科等赢家取消约束。

## 7. 验收与剩余未知

- 九月只有19个独立交易日，98周期并不等于98独立日期；版本更替还进一步缩小每个稳定规则样本。九月用于定位问题、提出固定假设，不同时用于调参和宣称改进。
- 工程/合同修复先做相关边界测试，再走既有受控发布；收益型候选通过同批冻结数据、时间隔离与自然前向验证。若进入晋级预测模型替换，应遵守ashare评估政策的至少30交易日、50正样本、2种市场状态、按日聚类配对bootstrap等门，不能拿策略成交笔数冒充模型验收样本；其他路线使用各自治理标准。
