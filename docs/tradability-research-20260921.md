2. 右侧：精确 signal_log_id + account + code + event_key 链接原订单、fill_id、trade_id；核对数量、价格、版本、费用、源钟顺序/原有效期、原盘口分配与同账户容量、回报合同状态及账本输入SHA。
3. 右侧只能证明已有**本地模拟成交回报可关联且字段合同相符**。不重跑风险引擎，不证明交易所成交、历史全量PIT或物理commit时钟；账本physical_commit仍可为空。
4. 没有回报者保留原拒因，反事实成交unknown，不将未知记作亏损0、成交0概率或已通过门禁。
5. 9/21新买的T+1退出尚不可评估；不把9/21收盘估值写作卖出收益。
6. 冻结原firstboard分类、quota条件配对与limitup_learning精确链接直接复用，不重建平行策略。没有比较不同阈值、寻优或选最优子组。

这是**同规则证据层配对**，不是“取消确认”和“原确认”的收益A/B。报价字段覆盖与真实成交回报是不同时间锚的旁列，不可强行串成逐级递减漏斗。
