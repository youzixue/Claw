# Claw 新会话任务自动路由（2026-10-01）

## 已启用

工作区本地 Host 插件 `@local/claw-task-router`，仅处理 `/Users/youzix/WorkBuddy/Claw` 中新建、无历史任务且非派生的会话。启动先设标准模式，在原生 GUI 首次任务提交、模型启动前进行确定性分类，通过 `agentPresets.select` 真正切换模式，然后交回原生 gateway 校验及入队。不是提示词模拟切换，也不改变模型。

| 任务 | 自动模式 |
| --- | --- |
| 一般分析、模拟盘复盘、代码修复、交易/风控修改、混合或不确定任务 | 标准 |
| 明确只读的批量 MCP/行情证据读取、分页筛选及汇总，且不包含修改/部署/导出要求 | PTC |
| 明确开发、安装或调试 DSH/Cordis 插件 | 创造（cordis） |
| 定时研究复盘 | 标准，并强制保留只读保护 |

不自动选择极简模式；明确专用模式不可用时回退标准，标准不可用则阻止提交。现有、恢复、分叉及子代理会话不自动切换。同一会话首次任务提交后固定，不逐轮改模式。新 Claw 会话的首次分类会覆盖原先手动选择的模式；没有新增 Auto 下拉项。

## 安全与边界

- 接入原生认证后的 `/api/session/prompt` HTTP 路径，保留原生请求 ID、附件验证、取消及入队语义，不 monkey-patch 原生服务。
- 其他直接 RPC/ACP 入口没有声称实现任务分类；新会话启动仍使用安全的标准默认。
- 分类最多32KiB，传输最多1MiB；确定性规则，不调用分类模型、不写任务正文或逐任务报告。内存中只保留最多200项路由决策。
- 原生 schedule 使用 JSON 包装的提醒已补充识别；在所有四个 preset 中验证无人值守只读规则和80次/20分钟预算，不因模式改变放宽权限。
- 不修改交易策略、数据库、采集、下单或推送；不复制数据库、分钟归档或大型研究文件。08:00/15:30定时设置不变。
- 插件本身未设置任意业务任务的权限；PTC 不等于只读，定时复盘的只读性由独立 Host guard 强制实施。
