# 模型评估与晋级策略

## 漏斗分层

1. **候选召回**：真实目标是否进入宽候选池。
2. **排序**：已入池目标是否进入固定 Top-K 主榜。
3. **校准**：预测概率是否与观察频率一致。
4. **可执行性**：交易门禁、涨停不可成交、流动性和风险限制。

只改变阈值无法修复候选召回；扩大候选池也不能证明排序提升。每个实验只能主攻一个层级。

## 时间验证

- 按交易日排序，采用 expanding/rolling walk-forward；禁止随机切分。
- 每折只用验证日前数据拟合；概率校准尾窗也必须早于验证窗。
- 同一代码/日期/目标只保留同上下文最新冻结快照，不能让后续快照覆盖历史预测。
- 数据守门至少检查样本数、交易日数、正样本数、风格覆盖和候选预筛召回。

## 指标

主要指标：

- PR-AUC / Average Precision（低基准率排序）
- Brier score、log loss、ECE（概率可信度）
- 每日 Top-5/12/30 精度、召回、lift
- 宽候选池召回
- 按市场风格的相同指标

准确率、单日涨停数或单一 Top-K 命中不能独立作为晋级依据。

## 状态流转

`registered/pretrained -> offline_rejected 或 shadow_eligible -> shadow -> approved_champion -> retired`

- 历史 K 线面板产物最多为 `pretrained`。
- 冻结预测快照通过全部离线闸门后为 `shadow_eligible`。
- 影子运行必须在同一不可变生产候选集上做 Champion / Challenger 配对，不下单、不替换 Champion；累计验收至少覆盖 30 个交易日、50 个正样本和 2 个可评估风格，并按交易日成组做 500 次配对 bootstrap，核心增益的 90% 置信下界不得为负。
- 只有 `manual_review_eligible` 才能人工晋级；审批必须记录操作人、理由、证据评估和精确确认短语，系统永不自动审批。
- 晋级后的挑战者只主导已召回候选的概率排序，不能绕过召回、交易性或风险闸门。
- 任一数据质量、漂移、校准或执行风险闸门失败时通过追加式回滚事件恢复上一 Champion，历史证据不得改写。
- 生产读取和回滚恢复都必须重新校验产物 SHA-256、当前标签/评估版本及完整验收策略；证据过期或被篡改时 fail-closed 到 Legacy，重新收集证据并人工审批，禁止旧审批自动复活。

## 每日学习边界

每日可以自动完成：补标签、质量审计、复盘快照、结构化归因、漂移监控、离线候选实验。

每日不得自动完成：根据当天输赢改生产权重、删除失败历史、改变标签定义、把挑战者晋级为 Champion、绕过风险门禁。
